```

#### 2. Deploy Backend → [render.com](https://render.com) (FREE)

- Add these environment variables:
  ```
  TELEGRAM_BOT_TOKEN=8028946023:AAFw5-YD6oC5i4lhZfqgVxwBEizLIulzJks
  TELEGRAM_CHAT_ID=6101360046

#### 3. Deploy Frontend → [vercel.com](https://vercel.com) (FREE)
- Sign up (free)

  ```
  REACT_APP_API_URL=[paste your backend URL]
  ```
- Deploy!
